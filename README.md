# 🎭 Playwright Python Automation

End-to-end UI test automation scripts built with **Playwright** and **Python**, covering real-world web interactions and automation scenarios.

## 🚀 Topics & Scenarios Covered
* **Form & Input Handling:** Textboxes, radio buttons, checkboxes, dropdowns, and date pickers
* **File Operations:** Single and multiple file uploads (`set_input_files`)
* **Mouse & Keyboard Actions:** Drag-and-drop, sliders, hover, double-click, and keyboard shortcuts
* **Alerts & Windows:** JavaScript dialogs (Simple, Confirmation, Prompt), new tabs, and popup windows
* **Frames & Shadow DOM:** Single iframes, nested iframes, dynamic payment frames, and Shadow Root piercing
* **Web Tables & Link Validation:** Static/dynamic tables, pagination filtering, and element/link counting

## 🛠️ Tech Stack
* **Language:** Python
* **Automation Framework:** Playwright (`playwright.sync_api`) & Pytest
* **Tools:** VS Code, Git & GitHub

## ⚙️ How to Run Locally
1. **Clone the repository:**
   ```bash
   git clone https://github.com/pratheeksha4shetty/playwright-python-automation.git
   cd playwright-python-automation
   ```
2. **Install dependencies & browsers:**
   ```bash
   python -m pip install playwright pytest pytest-playwright
   python -m playwright install
   ```
3. **Run any script:**
   ```bash
   python test_playwright1.py
   ```
